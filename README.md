# 🏎️ BMW Executive Sales & Performance Dashboard

An interactive high-end automotive analytics dashboard built in Power BI, featuring a cinematic dark theme (`#0B0E14`), BMW blue accents, and a custom **Glassmorphic UI** designed in Figma.

## 📌 Project Overview
This project delivers deep, data-driven business intelligence for BMW sales performance across multiple regions and model lines from 2022 to 2024. It combines advanced UI/UX principles with seamless cross-page interactivity to provide an executive-level reporting experience.

## 📊 Key Features & Dashboard Pages

1. **Executive Overview Page:**
   * **High-Level KPIs:** Total Revenue (~4T), Total Units Sold (52M), Average Unit Price, and Average Mileage[cite: 6].
   * **Sales Performance Trend:** Combined analytical container tracking sales volume and revenue by model over the years[cite: 6].
   * **Market Specs Breakdown:** Clustered bar chart breaking down sales by fuel types and global regions[cite: 6].

2. **Model-Specific Studio Pages (i8, M3, X3, X6):**
   * Dedicated analytical pages for each iconic model[cite: 7].
   * Custom navigation controllers (Forward/Backward arrows) for smooth vehicle cycling.
   * Specific performance metrics, unit pricing, and revenue trends per model[cite: 7].

3. **Global Slicers & Interactivity:**
   * Synced time filters across all pages (2022 - 2024).
   * Cross-page navigation backed by transparent glassmorphic UI panels.

## 🛠️ Tech Stack & Tools
* **Power BI Desktop:** Data modeling, DAX measures, and visual formatting.
* **Figma:** Designing custom dark aesthetic and glassmorphism background layouts.
* **DAX:** Calculated columns and custom aggregation measures.
